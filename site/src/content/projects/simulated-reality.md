*2009-2019: Research at UHasselt*
![Project preview](../../../public/Projects/Snakecharmer/cover.png)

We built a system to prototype tactile interfaces without building every prototype. The tester sees the interface in VR, and a robot moves the relevant elements in front of the finger of the tester. 

The haptic interface must only be made once, with one of each element on the panel. Then the actual interface is designed in Unity 3D, and shown in VR. When moving close to an element in VR, the physical root moves the corresponding element in front of the finger, and passes the physical interaction on to the virtual element. The tester will experience the virtual interface as a real, haptic, one.

You can find the paper [here](https://github.com/pgoorts/Portfolio/raw/refs/heads/main/files/Publications/vandeurzen2021hapticpanel.pdf)
